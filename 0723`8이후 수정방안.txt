2. Legend Box 시작 위치(X, Y) 선택적 입력 옵션 추가
Gnuplot에서 범례(Key)의 위치는 기본적으로 right top, left bottom 같은 키워드로 지정하지만, at graph x, y 또는 at screen x, y 구문을 사용하면 사용자가 원하는 정확한 좌표에 범례 박스를 배치할 수 있습니다.

@dataclass
class PlotDefinition:

③ _build_plot_commands 내에서 범례 위치 명령어 반영 로직 수정
_build_plot_commands 메서드 안에서 범례 위치를 설정하는 부분을 아래와 같이 수정하여, 사용자가 커스텀 좌표를 체크했을 때 
at graph X, Y 구문이 생성되도록 합니다.

if plotdef.legend_on:
    box = f"box linewidth {1.5 * border_scale}" if plotdef.legend_box else "nobox"
    opaque = "opaque" if plotdef.legend_box else ""

    # [수정] 사용자 정의 좌표가 활성화된 경우 처리
    if getattr(plotdef, "legend_custom_pos", False):
        lx = getattr(plotdef, "legend_x", "0.8")
        ly = getattr(plotdef, "legend_y", "0.8")
        pos = f"at graph {lx}, {ly}"
    elif plotdef.legend_pos == "outside right":
        if not is_multiplot:
            lines.append("set rmargin at screen 0.78")
        pos = "outside right center"
    else:
        if plotdef.legend_box and plotdef.legend_pos.startswith("right") and not is_multiplot:
            lines.append("set rmargin at screen 0.88")
        pos = f"inside {plotdef.legend_pos}"

    lines.append(
        f'set key enhanced {pos} {box} {opaque} '
        f'font "{plotdef.xlabel_font},{int(9*f_scale)}" '
        f'samplen 2.5 spacing 1.2'
    )
else:
    lines.append("unset key")


1. 특정 커브를 Legend에서 숨기기 (notitle)
만약 특정 곡선이 Y2축용이거나 보조선이어서 범례 박스를 지저분하게 만든다면, 해당 곡선을 그릴 때 제목에 notitle 옵션을 주어 범례 목록에서 아예 제외시킬 수 있습니다.

코드 수정 아이디어 (_build_plot_commands 내부):
CurveDefinition 클래스에 범례 표시 여부를 결정하는 옵션(예: show_in_legend: bool = True)을 추가하고, 명령어 생성 시 분기 처리합니다.

# CurveDefinition에 필드 추가 예시
@dataclass
class CurveDefinition:
    # ... (기존 필드) ...
    show_in_legend: bool = True  # 범례 표시 여부 토글용

명령어 생성 부근 반영:

if curve.show_in_legend:
    curve_title_text, curve_title_enh = self._render_text(curve.title)
    title_clause = f'title "{curve_title_text}" {curve_title_enh}'
else:
    title_clause = 'notitle'

cmd = f'"{path}" using {using_expr} {title_clause} axes {axis} with lines lw {lw}'

2. Y1, Y2 축 별로 범례 박스를 따로 두고 싶을 때의 대안 (멀티플롯 활용)
만약 Y1축 데이터용 범례와 Y2축 데이터용 범례 박스를 완전히 독립된 위치에 각각 따로 띄우고 싶다면, Multiplot 기능으로 동일한 영역에 두 번 겹쳐 그리는 방식을 사용해야 합니다.

첫 번째 패널: Y1축 곡선들만 그리면서 범례를 왼쪽 상단(left top)에 배치합니다. (이때 Y2축 곡선들은 notitle 등으로 숨기거나 그리지 않음)

두 번째 패널 (투명 오버레이): 동일한 좌표계 위에 Y2축 곡선들만 그리면서 범례를 오른쪽 상단(right top)에 배치합니다. (이때 X/Y축 레이블이나 눈금은 투명하게 처리하거나 숨김)

대다수의 경우 1번의 notitle 옵션(특정 곡선 범례 끄기/켜기)을 DAT 파일 설정 영역이나 곡선 설정 패널에 체크박스로 추가해 주는 것이 가장 직관적이고 간편합니다.

요청하신 대로 필요할 때만 동적으로 넣고 뺄 수 있도록(Dynamic Add/Remove) 인터페이스를 구성하는 것이 훨씬 깔끔하고 실용적입니다.

PyQt 기반 환경에서 DAT 파일 행(Row)별로 범례 표시 여부(Show Legend)나 기타 상세 제어 옵션을 접었다 폈다 하거나(Collapsible), 우측 마우스 메뉴(Context Menu) 또는 토글 버튼을 통해 필요할 때만 동적으로 팝업·생성할 수 있는 설계 방안입니다.


클래스를 활용하면 각 DAT 파일 행마다 파일 선택, 축 지정, 기본 설정만 깔끔하게 노출하고, 상세 색상(Color)이나 선 스타일(Style), 범례 표시 여부(Show Legend) 같은 복잡한 옵션들은 우측의 ?? Style 버튼을 눌렀을 때만 팝업(또는 토글)되도록 숨길 수 있어 패널 공간을 대폭 절약할 수 있습니다.

DAT 행 관리 및 스타일 동적 제어를 위한 DatRowWidget 구조
from PyQt5.QtWidgets import (QWidget, QHBoxLayout, QLineEdit, 
                             QPushButton, QComboBox, QDialog, QVBoxLayout, QCheckBox, QLabel)

class DatRowWidget(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        
        # 데이터 저장을 위한 기본 속성값 정의
        self.file_path = ""
        self.color = "blue"
        self.style = "lines"
        self.show_in_legend = True
        
        self._init_ui()

    def _init_ui(self):
        layout = QHBoxLayout(self)
        layout.setContentsMargins(0, 0, 0, 0)

        # 1. 파일 경로 입력 (또는 선택) 필드
        self.path_input = QLineEdit(self)
        self.path_input.setPlaceholderText("Select or enter .dat file path...")
        
        # 2. X, Y 열 번호 지정 콤보박스 또는 입력란
        self.x_col_input = QLineEdit("0", self)
        self.x_col_input.setFixedWidth(40)
        self.y_col_input = QLineEdit("1", self)
        self.y_col_input.setFixedWidth(40)

        # 3. 축 선택 (Y1 / Y2)
        self.axis_combo = QComboBox(self)
        self.axis_combo.addItems(["Y1", "Y2"])

        # 4. [핵심] 공간 절약을 위한 상세 설정 팝업 버튼 (Color, Style, Legend 제어)
        self.btn_detail_style = QPushButton("?? Style", self)
        self.btn_detail_style.setFixedWidth(70)
        self.btn_detail_style.clicked.connect(self.open_detail_style_dialog)

        # 5. 행 삭제 버튼 [X]
        self.btn_delete = QPushButton("X", self)
        self.btn_delete.setFixedWidth(30)

        # 레이아웃에 위젯들 배치 (기본 화면은 슬림하게 유지)
        layout.addWidget(self.path_input, stretch=4)
        layout.addWidget(QLabel("X:"))
        layout.addWidget(self.x_col_input)
        layout.addWidget(QLabel("Y:"))
        layout.addWidget(self.y_col_input)
        layout.addWidget(self.axis_combo)
        layout.addWidget(self.btn_detail_style)
        layout.addWidget(self.btn_delete)

    def open_detail_style_dialog(self):
        """?? 버튼을 누를 때만 동적으로 나타나는 세부 설정 팝업 창"""
        dialog = QDialog(self)
        dialog.setWindowTitle("Curve Detail Settings")
        dialog.resize(300, 200)
        
        dlg_layout = QVBoxLayout(dialog)

        # 색상 선택 콤보박스
        color_layout = QHBoxLayout()
        color_layout.addWidget(QLabel("Color:"))
        self.combo_color = QComboBox()
        self.combo_color.addItems(["blue", "red", "green", "black", "orange", "purple"])
        self.combo_color.setCurrentText(self.color)
        color_layout.addWidget(self.combo_color)
        dlg_layout.addLayout(color_layout)

        # 선 스타일 선택 콤보박스
        style_layout = QHBoxLayout()
        style_layout.addWidget(QLabel("Line Style:"))
        self.combo_style = QComboBox()
        self.combo_style.addItems(["lines", "points", "linespoints", "impulses"])
        self.combo_style.setCurrentText(self.style)
        style_layout.addWidget(self.combo_style)
        dlg_layout.addLayout(style_layout)

        # 범례 표시 여부 체크박스 (Show Legend)
        self.chk_legend = QCheckBox("Show in Legend", dialog)
        self.chk_legend.setChecked(self.show_in_legend)
        dlg_layout.addWidget(self.chk_legend)

        # 확인 버튼을 누르면 설정값 반영 후 닫기
        btn_apply = QPushButton("Apply & Close", dialog)
        btn_apply.clicked.connect(lambda: self.save_dialog_values(dialog))
        dlg_layout.addWidget(btn_apply)

        dialog.exec_()

    def save_dialog_values(self, dialog):
        """팝업 창에서 선택한 값을 클래스 변수에 저장"""
        self.color = self.combo_color.currentText()
        self.style = self.combo_style.currentText()
        self.show_in_legend = self.chk_legend.isChecked()
        dialog.accept()

        dlg_layout.addWidget(QLabel("Enter X Column Index (0-based):"))

                pass
