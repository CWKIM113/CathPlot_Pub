Python EXE Packing 방법:
1. Installer 설치
pip install pyinstaller
pip install pywin32
2. EXE 만들기
빠른 실행:
pyinstaller --noconsole --onedir --name CathPlot --collect-all pywin32 cathplot_gui.py
한 파일로 압축: 실행시 압출푸는데 시간 걸림
pyinstaller --noconsole --onefile --name CathPlot --collect-all pywin32 cathplot_gui.py

3. 실행
자체 실행은 빈 cmd 창 없이 가능하나 Bat 등을 활용하면 빈cmd창 생성됨.
빈 cmd창 없애는 방법:
- VbScript 활용법 (2027 이후 Windows에는 사용 못할 듯): run.vbs
' 빈 cmd 창없이 실행하기
Set objShell = CreateObject("WScript.Shell")
objShell.CurrentDirectory = Left(WScript.ScriptFullName, InStrRev(WScript.ScriptFullName, "\"))
rem objShell.Run """D:\CathPlot\dist\CathPlot\CathPlot.exe"""
objShell.Run """D:\CathPlot\dist\CathPlot\CathPlot.exe"""

- Power Shell 이용법 (약간 지연시간 있음): run.bat
' 빈 cmd 창없이 실행하기
Set objShell = CreateObject("WScript.Shell")
objShell.CurrentDirectory = Left(WScript.ScriptFullName, InStrRev(WScript.ScriptFullName, "\"))
rem objShell.Run """D:\CathPlot\dist\CathPlot\CathPlot.exe"""
objShell.Run """D:\CathPlot\dist\CathPlot\CathPlot.exe"""
